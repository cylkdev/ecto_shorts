# Project

EctoShorts is an Elixir library that wraps Ecto to provide a concise, data-driven API for common database operations — it lets you express query filters, CRUD actions, changeset helpers, and dynamic expressions as plain maps or keyword lists rather than writing verbose Ecto query pipelines by hand, with modules like Actions, CommonFilters, CommonChanges, CommonSchema, CommonParams, CommonQuery, and Dynamics each covering a focused slice of the data-access layer so that day-to-day repository interactions require significantly less boilerplate code.
