# Markdown Writing Conventions

## Requirements

Use these writing conventions for all markdown you output.

## Guidelines

### Headers

Use `#` for top-level headers, `##` for second-level headers, and `###` for third-level headers. Do not use `####` or higher.

### Lists

Use `-` for unordered lists and `1.` for ordered lists.

### Indentation

Do not use triple backticks. Use 2 spaces for indentation.

Do not do this:

```elixir
# BAD EXAMPLE, DO NOT COPY!
defmodule SomeModule do
...
end
```

Do this:

    # GOOD EXAMPLE, COPY THIS!
    defmodule SomeModule do
    ...
    end
