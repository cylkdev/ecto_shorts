## When to use

Use when you are writing or modifying code.

## What to do

When writing or modifying code:

1. Identify the type of code you are writing

2. Identify any code style rules or guidelines defined in this project for the type of code you are writing

3. Apply all relevant code style rules or guidelines to the code you are writing
