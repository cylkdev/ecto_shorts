## When to use

Use this skill when the current unresolved question is how to write or update one reusable code style rule.

## When not to use

Do **not** use this skill when the task is only to apply an existing style rule during implementation or review. Use the matching skill instead.

## What to do

1. Read `.windsurf/workflows/code-style-rule.md`.

2. Treat `.windsurf/workflows/code-style-rule.md` as the source of truth.

3. Execute that workflow exactly as written.
