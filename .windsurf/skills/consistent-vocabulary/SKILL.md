---

## When to use

Use this skill when the current unresolved question is whether a set of markdown files uses inconsistent vocabulary.

## When not to use

Do **not** use this skill for general copy editing or for revising one document without comparing vocabulary across multiple markdown files.

## What to do

1. Read `.windsurf/workflows/consistent-vocabulary.md`.

2. Treat `.windsurf/workflows/consistent-vocabulary.md` as the source of truth.

3. Execute that workflow exactly as written.
