## When to use

Use this skill when the current unresolved question is which behaviour to accept at one user-observable boundary.

## When not to use

Do **not** use this skill when behaviour is already accepted and the current unresolved question is proof-ready specification or implementation sequence. Use the matching skill instead.

## What to do

1. Read `.windsurf/workflows/example-mapping.md`.

2. Treat `.windsurf/workflows/example-mapping.md` as the source of truth.

3. Execute that workflow exactly as written.
