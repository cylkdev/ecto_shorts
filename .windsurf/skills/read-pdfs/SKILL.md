## When to use

Use this skill when the current unresolved question is how to export one PDF, a directory of PDFs, or wildcard-matched PDFs into readable Markdown or page images.

## When not to use

Do **not** use this skill for unrelated PDF tasks such as renaming PDFs, moving PDFs, deleting PDF files, or editing the PDF itself when the goal is not to export readable Markdown or page images.

## What to do

1. Read `.windsurf/workflows/read-pdfs.md`.

2. Treat `.windsurf/workflows/read-pdfs.md` as the source of truth.

3. Execute that workflow exactly as written.
