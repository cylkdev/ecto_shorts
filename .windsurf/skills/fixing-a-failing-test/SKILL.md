## When to use

Use this skill when the current unresolved question is how to diagnose, fix, and validate one failing Elixir test.

## When not to use

Do **not** use this skill for general test verification when there is no specific failing test to investigate. Use the `run-tests` skill instead.

## What to do

1. Read `.windsurf/workflows/fixing-a-failing-test.md`.

2. Treat `.windsurf/workflows/fixing-a-failing-test.md` as the source of truth.

3. Execute that workflow exactly as written.
