## When to use

Use this skill after changing Elixir code, tests, or project configuration and you need to verify linting and code-quality checks with Credo.

## When not to use

Do **not** use this skill to run Dialyzer or tests. Use the matching skills for those tools instead.

## What to do

1. Read `.windsurf/workflows/run-credo.md`.

2. Use `.windsurf/workflows/run-credo.md` as the source of truth for the exact step-by-step procedure.

3. Execute that workflow exactly as written.
