## When to use

Use this skill when the current unresolved question is how to sequence a behaviour-changing implementation.

## When not to use

Do **not** use this skill when the current unresolved question is diagnosis, intended behaviour, or a behaviour-preserving structural change. Use the matching skill instead.

## What to do

1. Read `.windsurf/workflows/exec-plan.md`.

2. Treat `.windsurf/workflows/exec-plan.md` as the source of truth.

3. Execute that workflow exactly as written.
