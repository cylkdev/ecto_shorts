## When to use

Use this skill when the current unresolved question is how to sequence a safe structural change that preserves observable behaviour.

## When not to use

Do **not** use this skill when the task intentionally changes behaviour or when the current unresolved question is diagnosis. Use the matching skill instead.

## What to do

1. Read `.windsurf/workflows/refactor-plan.md`.

2. Treat `.windsurf/workflows/refactor-plan.md` as the source of truth.

3. Execute that workflow exactly as written.
