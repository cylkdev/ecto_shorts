name: investigation-log

---

## When to use

Use this skill when the current unresolved question is what visible failure or unexpected result is actually happening and why its cause is not yet proven.

## When not to use

Do **not** use this skill when the cause is already proven and the current unresolved question is intended behaviour or implementation sequence. Use the matching skill instead.

## What to do

1. Read `.windsurf/workflows/investigation-log.md`.

2. Treat `.windsurf/workflows/investigation-log.md` as the source of truth.

3. Execute that workflow exactly as written.
