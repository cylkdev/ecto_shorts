## When to use

Use this skill when setting up a new elixir project.

## Requirements

- Read `.agent/PROJECT.md` and load it into your context. If it is already loaded, read it again and refresh your memory. Follow it to the _letter_.

## What to do

1. Create a new elixir application using one of the commands described in `.agent/PROJECT.md`. Applications should include an application supervisor as the default when not specified.

2. Review each `mix.exs` file in the project in parrallel:
  - add the required dependencies
  - add the `elixirc_paths` configuration
  - add the `dialyzer` configuration

3. Create a `.formatter.exs` file in the root of the project and/or in the root of each child application if it does not already exist.

4. Create a `.credo.exs` file in the root of the project and/or in the root of each child application if it does not already exist.

5. Add the `credo` configuration to the `mix.exs` file at the root of the project and/or in the root of each child application if it does not already exist.

6. Create a `.dialyzer-ignore.exs` file in the root of the project if it does not already exist.

7. Add the `dialyzer` configuration to the `mix.exs` file at the root of the project and/or in the root of each child application if it does not already exist.

8. Clean up the `hello_world` function in the service module and the test file that was generated by mix.

9. Run the following commands in parallel:

- `mix credo --strict`
- `mix dialyzer`
- `mix test`

10. Wait for all commands to complete.
