## When to use

Use this skill when the current unresolved question is how to review the architecture of a system or subsystem and produce an ArchitectureReview.

## When not to use

Do **not** use this skill when the current unresolved question is one isolated bug, one user-observable boundary, or one implementation sequence. Use the matching skill instead.

## What to do

1. Read `.windsurf/workflows/architecture-review.md`.

2. Treat `.windsurf/workflows/architecture-review.md` as the source of truth.

3. Execute that workflow exactly as written.
