## When to use

Use this skill when the current unresolved question is whether to record one lasting architectural or design decision in an ADR.

## When not to use

Do **not** use this skill when the current unresolved question is diagnosis, intended behaviour, or implementation sequence. Use the matching skill instead.

## What to do

1. Read `.windsurf/workflows/adr.md`.

2. Treat `.windsurf/workflows/adr.md` as the source of truth.

3. Execute that workflow exactly as written.
