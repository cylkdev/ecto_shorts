# What to do

Write a changelog entry that captures user-facing changes to the public API after completing a set of code changes.

## When not to use

Do **not** use this workflow for purely internal refactors, code style fixes, or implementation changes that leave the public interface identical.

## How to do it

1. Invoke the `write-changelog` skill.
