## Windsurf

Windsurf is a code assistant that helps you write code faster and with less errors. It can also help you understand code better and make it more maintainable.

### Global Rules

Global rules are applied to all code in the project. They are stored in the following file:

```
~/.codeium/windsurf/memories/global_rules.md
```

### Global skills

Skills placed in the `~/.codeium/windsurf/skills` folder are applied to every project.

They are stored in the format:

```
~/.codeium/windsurf/skills/<skill-name>/SKILL.md
```

### Global workflows

```
~/.codeium/windsurf/global_workflows/
```
